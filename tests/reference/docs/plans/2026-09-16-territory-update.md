# 随机节点与多边形领地

用户变更：每局随机 12–16 节点，随机均匀分布；节点与基地共同分割全地图，分区数量等于二者之和；基地受击范围加线条标注。

- 采用 best-candidate 空间采样，节点距离其他节点及基地至少 140 格，距离边界至少 60 格。比独立均匀随机更少聚团，不使用固定网格。
- 对所有基地、节点生成裁剪至 1000² 地图的 Voronoi 多边形。分区固定，只有归属变化；基地被摧毁后其分区中立，分区数量保持不变。
- 部署按活细胞逐个验证最近站点的归属，跨入非己方分区则整次拒绝；相邻己方多边形可跨区部署。平分线上的格子使用固定站点顺序消除歧义。
- 服务端与浏览器共用几何和归属函数；浏览器在首次状态/重连时生成几何，后续仅更新归属，不增加每 tick 的多边形传输。
- 主地图和小地图绘制全部分区边界与阵营填色。基地 12 格实际受击圆使用真实缩放绘制，带引线文字标注。
- 中立站点无法直接投放锚点，更新教程并让 AI 使用滑翔机/飞船从己方领地发射至目标。
- 验证：120 张 2–4 人随机地图的数量、间距、覆盖与面积；共享边界、归属转移、跨区部署原子性、客户端一致性、12 格伤害边界、AI 实际占领；保留原规则/联机回归测试。
