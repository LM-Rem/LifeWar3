# LifeWar / NEXUS Implementation Plan

**Goal:** 制作可在局域网运行的 2–4 人康威生命游戏 PVP，包含起始页、房间与全屏战场。

**Architecture:** Node.js 权威房间服务器以固定 10 Hz 演化，客户端 Canvas 2D 以屏幕刷新率渲染。1000×1000 有界网格使用类型数组与稀疏候选列表，只计算活细胞及其邻居；WebSocket 二进制增量同步，加入/重连发送快照。无外部 CDN，断网局域网可用。

**Tech Stack:** Node.js 24, ws, 原生 ES modules, Canvas 2D, CSS。

## 规则与实现决策
- B3/S23，存活细胞保持阵营，出生由三个邻居多数决定；三方平票按坐标与代数确定，避免固定玩家优势。
- 基地分布于地图四角内侧。基地部署半径 170，节点半径 125。部署每细胞消耗 1 能量，初始 120、上限 180、恢复 5/s，每个节点 +1/s。
- 节点附近 10 格内存在单一阵营细胞时积累占领进度，3 秒占领；争夺时冻结，空置缓慢衰减。占领永久保留至被夺取。
- 基地 240 HP，敌细胞进入基地 12 格范围时消耗并造成 3 点伤害；每个 tick 最多 15 点。禁止在敌基地 28 格内直接部署。
- 淘汰移除所属细胞与节点。最后一个存活玩家胜利。无暂停，退出需确认，断线可用本地令牌重连，90 秒离线判负。
- 每玩家最多 6000 活细胞，全局 24000；达上限仍演化存量，拒绝新增部署，出生按稳定顺序受容量限制。预设/自定义图案最大 32×32、256 细胞。

## 实施步骤
1. `src/engine.js`：模拟、部署校验、资源、节点、胜负；`tests/engine.test.js` 验证标准模式、阵营、边界、规则与胜负。
2. `src/server.js`：静态服务、房间、准备、开局、机器人、心跳、重连、校验与二进制同步；`tests/network.test.js` 使用真实多客户端验证。
3. `public/index.html`, `public/style.css`, `public/app.js`, `public/renderer.js`, `public/patterns.js`：三页流程、视觉效果、地图操作、可折叠 HUD、自定义图案、音效与帮助。
4. `tests/benchmark.js`：稀疏模拟压力数据；浏览器验收页面、部署、旋转翻转、镜头和房间切换。
5. `README.md`：启动、局域网接入、控制、玩法、边界与测试说明。

## 验收
`npm test` 全部通过；`npm run benchmark` 记录实际指标；本地服务 0.0.0.0:3000 可用；浏览器截图检查并修正；提供真实局域网地址与启动方法。
