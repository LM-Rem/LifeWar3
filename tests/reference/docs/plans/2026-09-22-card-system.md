# 卡牌系统实施计划

目标：将卡牌草案改为可配置、可读、服务器权威的完整玩法，保留已修复的 PC/触屏拖动。

1. 建立 cards.json：26 张卡，三轮每轮各抽法则/增益/道具一张，拒绝 B0 和非法参数。
2. 引擎：实际时间计时、全局法则预告/替换、局部优先；定时增益与一次性部署增益；生成/清除棋盘保持原子性与增量一致。
3. 生命周期：30 秒选卡期限；满手可明确换卡，超时保留旧卡/空手自动选增益；淘汰与重连清理/恢复；玩家私有候选与手牌。
4. 前端：全局预告/倒计时、己方增益、选点与取消、动态费用/容量/领地预览、移除示例假卡。
5. AI：识别所有效果，生成卡避开核心，范围攻击选择敌军，遵守相同校验。
6. 验证：假时钟覆盖时效/过期/叠加，边界与非法请求，网络重连/私有性，保留拖动回归；隔离本地配置使测试可重复，浏览器检查。

详尽规则与取舍记录在 docs/卡牌实现.md。原始卡牌设计.md 保留用户编辑内容。
