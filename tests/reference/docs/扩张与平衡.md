# 扩张、节点压制与卡牌平衡（2026-09-23）

## 节点压制

`config.json` 的 `nodeDamageStartSeconds: 600` 与 `nodeDamagePerSecond: 0.1` 是参数来源。第600秒进入压制期，第601秒结算第一秒伤害，此后与演化频率无关。每个存活阵营的每个节点对所有敌方核心各造成0.1伤害，中立节点不参与。以本次结算开始时的节点归属计算，所有核心先受伤，再统一淘汰，允许平局。

支持小数耐久，界面保留一位小数。护盾同时抵挡细胞接触和节点压制。服务器延迟时补算遗漏的现实秒，节点归属采用最近一次服务器结算时的状态，护盾覆盖按有效期逐秒排除；不补演化。界面显示开启倒计时和节点伤害率。

## 扩张

彻底取消全局24,000上限，旧maxCells字段不再读取；出生与存活不检查个人容量。个人playerCells只用于校验手动部署以及播种/星云的新增细胞总量。超过个人容量的自然种群不会被强删，仍正常参与演化、核心接触和休眠。

取消出生候选的临时二维数组，直接写入下一代棋盘，减少大规模繁殖时的对象分配。地图仍为1000×1000，不环绕；数量不设游戏配额不代表计算和渲染开销无限。

## 法则扩充

新增概率法则（early，4秒）、异变纪元（mid，6秒）、混沌宇宙（late，8秒）。每张都在候选生成时抽取规则，玩家选牌前能看到结果；手牌和重连保留原结果，施放不重新抽取。每张获得的卡有独立instanceId，避免同名但不同规则的卡片混用。

新增「阵营同化」（mid）：20秒内，凡新生细胞的8邻居中有施法者细胞，则归施法者。只改归属，不改变出生资格和原有细胞阵营；没有己方邻居时正常投票。两个及以上不同阵营同时激活时，全场恢复普通多数/平票判定，不只限于有争议的局部；其中一方到期或淘汰后，剩余单方效果恢复。重复施放只刷新持续时间。该法则独立于全局B/S规则，二者可共存。

## 数值调整依据

不同类型的收益依赖战局，无法以一个固定分数保证等价。本轮消除明显量级差异，并保留战术条件：

- 能量爆发改为基础能量上限35%，核心修复为耐久上限25%，适配本项目1000能量/100耐久及其他配置。
- 过载改为上限+25%、获得35%基础能量；取消直接回满，避免与能量涌动重复且更强。
- 闪电部署保留绕过冷却，减免预算最多基础能量上限50%；大图案超过预算的部分付费，失败不消耗次数。优先于工程折扣，二者不同时打折。
- 超频延长至30秒；工程、占领、越界、固化保持原战术窗口。
- 增殖增加6000部署容量45秒，适应超额自然种群；熵减继续免疫休眠30秒。
- 大爆发与孤岛缩短至3秒、寂静3秒、倒退5秒、虚空2秒、洪水3秒；防止取消容量限制后长时间全场爆发/清空压倒其他选项。
- 播种升级为四艘重型飞船，共52细胞；仍整体检查碰撞、边界、核心禁区和个人部署容量。净化、星云、腐蚀保持局部战术用途。

## 验证与性能边界

自动化覆盖节点时间边界/多敌方/护盾/同时淘汰、同化少数优先/缺少己方/多方冲突/到期、所有固定法则、随机权重区间与持久化、同名变体精确消费、超额扩张与二进制增量一致性。

可运行 `npm run benchmark:expansion`。本机单房间、密集扩张、10次演化含增量打包：10万/30万/80万初始细胞平均约12/24/56ms，峰值约25/35/62ms。基准提高核心耐久以避免提前获胜停止演化；不关闭真实演化或偷偷恢复数量限制。这是服务器基准，不含浏览器绘制、真实网络和多房间负载；80万已超过当前20Hz的50ms预算，不能保证大规模实时帧率。卡牌强弱仍需多人实战调优。
