# 小地图背景失效范围与分层实验

保持原有逐格顺序、透明度、分数坐标和严格像素一致。沿用 Code 与 brainstorming 工作流；用户已授权实施。

1. 保留冻结基线。把几何变化与归属／基地状态变化分开；几何变化全量失效，样式变化根据领地边界和标记范围标记既有瓦片，保留贡献者索引。大范围变化继续完整重放。
2. 对节点归属、基地消灭／恢复、视角阵营、边界、无索引、密集包后背景变化做像素对照；三轮测量单节点与多节点背景变化。
3. 独立实验透明细胞层复用，先检查像素，失败则拒绝。不给生产路径增加未验证的分层缓存。
4. 运行规则与协议画面回归、密集单客户端复测，更新报告并明确仍未解决的全图成本。

完成：背景局部失效已采用，108 对三轮 A/B 像素一致；透明分层 12 组均有通道差异，拒绝采用。146 项自动化测试、376 项原始／协议画面比较及 32 项 Map 比较通过。普通单客户端通过本地门槛，密集单客户端仍有 353ms 长帧和队列峰值 7。下一阶段直接像素合成／GPU 后端需要独立 oracle 与最小原型，本轮未替换绘制后端。详见 [报告](../performance/2026-09-25-minimap-background.md)。
