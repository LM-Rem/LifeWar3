# 浅色圆角卡通主题

目标：增加完整的可切换主题，保留原 NEXUS 主题，覆盖首页、大厅、房间、战场、图案库、所有弹窗与动态内容。

视觉：奶油白纸面、薄荷绿主色、蜜桃/葡萄/蜂蜜阵营，圆角描边与轻微实体阴影。细胞呈糖豆形，节点为圆形标记，基地为带表情的圆形生命核心。地图保持真实分区几何和受击半径。

实施：
1. 同步主题启动脚本，在首屏绘制前读取 lifewar.settings；原设置无 theme 字段时使用 nexus。跨标签页同步；存储不可用时仍可切换。
2. 全站颜色使用按用途区分的 CSS 色彩变量，新增卡通形状、卡牌、控件与响应式样式；所有页面共用。
3. 绘图层共享调色板和圆角细胞绘制。战场近景使用有界的可见分块图集，远景及小地图保持像素纹理；切换时重建调色板并使缓存失效。
4. 首页提供卡通生命星球；图案预览、编辑器、图案库模拟、卡牌粒子和选点预览同步切换。
5. 浏览器验证切换、刷新、跨页/跨标签同步、所有弹窗、窄屏布局、棋盘不变和地图缓存。运行现有回归测试。

主题只改变呈现，不改变权威状态、协议、控制范围、演化顺序或卡牌结算。

- 固定棋盘验证主题切换不改变细胞、阵营、数量或代数；主地图和小地图切回后恢复相同画面。缓存覆盖出生、死亡、变更阵营和清空，图集最多保留 128 个分块。
