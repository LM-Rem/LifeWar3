# 纯通讯与基地警报调整

通讯面板及全屏历史仅保留玩家聊天，移除服务器和房间 worker 的事件转发，保留战场状态中的事件以继续驱动原有动画、音效及警报。客户端合并历史时过滤旧服务端事件，避免事件出现在消息预览或未读数中。更新标题、空状态、辅助说明和 README。

基地攻击提示使用独立 toast 标识；从出现到退场结束期间，同标识最多保留一个元素，消失后允许再次提醒，不影响其他提示。

验收：聊天模型与 inline/worker 联机集成确认纯聊天历史、背压独立及恢复；浏览器覆盖消息滚动/重连与主题布局，并确认连续多个己方伤害事件只生成一个警报、消失后可再次提示。保留移动端可视区域缩小模拟。

结果：13 项针对性测试通过，浏览器验收通过。Nexus/Cartoon、桌面/390px 窄屏、中文输入、历史滚动与刷新恢复正常；连续攻击警报最大并存数为 1，消失后能再次显示。透明度位置记录在 README 的操作说明中。

后续界面调整：手机通讯面板与战场态势统一为 154px 宽；手机和电脑端都移除时间，名字与内容连续显示，每条预览最多两行并省略超出部分。输入框改为单行，手机/触屏打开聊天先聚焦可滚动历史，点击输入框才进入输入状态。更新浏览器验收后，两种主题下的消息预览、输入类型、手机焦点、中文候选确认、Enter 发送、Shift+Enter 不换行/不发送及原有重连/滚动行为通过。
