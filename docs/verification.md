## 网络与边界

- 服务器监听 `0.0.0.0:3000`。
- 使用 Node 原生 HTTP 从本机直接请求 `127.0.0.1:3000/api/info` 与 `192.168.1.4:3000/api/info` 均返回 HTTP 200。
- 内嵌浏览器访问局域网 IP 的自动化读页超时；PowerShell Web 请求在该环境返回 502，而原生 HTTP 直连成功。这提示代理或预览环境存在差异，但未修改任何代理、防火墙或系统网络设置。
- 已完成本机四 WebSocket 客户端与双浏览器标签验收；**尚未完成第二台实体设备上的 Wi-Fi 对局测试**。
- 10–20 分钟为设计节奏目标，未完成多人长期平衡测试。AI 为基本练习对手。
- 手机布局有适配，但键鼠为主要交互，未进行真机触控验收。

## 验收中修正

- 初始镜头偏移，使最近节点不再被底部图谱遮挡。
- 所有基地先同时计算伤害，再执行淘汰，避免玩家顺序决定同时摧毁结果。
- 主动退出与离线结算时迁移房主权限。
- 对局结束后锁定结果，避免后续断线改变赢家，并停止重复广播终局。
- RLE 显式拒绝非 B3/S23 规则；保存图案后自动滚动到装备项。
- AI 进攻使用到目标对角线的投影并切换发射航道，改善非对角节点的攻击命中。
