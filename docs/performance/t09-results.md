# T09：变化前沿实验结果

2026-09-24。**功能与阶段验证完成；frontier 保留为显式可选后端，auto 继续使用 sparse。** 低变化负载受益，高变化未达到默认晋级门槛，也未通过全项目 20Hz 认证。

## 实现与等价性

- counts/votes 持久化；结果和脏标志各 1 byte/cell，1000×1000 棋盘额外缓存 2,000,000 字节（1.91 MiB）。未启用 frontier 的房间不分配这两个数组；启用后切走会失效并保留数组，供再次使用。
- recordChange 统一接收演化、部署、播种、净化、核心碰撞、消灭和休眠删除。变化格及八邻域失效，owner 替换也更新票数；决策和提交分离，不把同代新生细胞参与本代计算。
- 全局 B/S 和有效同化 owner 变化激活全部格；局部规则的旧、新圆域失效，保留覆盖顺序和圆边界。有效期检测沿用原逻辑。
- 每代仍按原 alive 顺序生成候选，重建 next/nextAlive、输出变化包并提交。平票使用当前 generation；没有跳代、合并代或冻结 alive 顺序。
- 一批演化变化超过 `max(256, nextAlive.length/4)`，或累计外部写超过 `max(256, alive.length/4)`，缓存失效，下一代使用 sparse 完整重建。模式切换和批量导入调用 `rebuildDerivedState()` 同样使缓存失效。选择 sparse 退路是基于现有 dense 更慢的测量结果。

复杂度仍包含每代 O(L+C) 保序遍历和 O(N) next 清空；只将邻居计数维护与部分规则计算缩小到变化前沿，不能宣称完整引擎为 O(D)。大幅局部规则变更也会增加圆域标记成本。

## 五轮独立进程对照

每场景/模式 5 个独立 Node 进程，交替模式顺序，30 代预热、100 代采样，共 500 个采样。计时为完整 `step + v1 packet`，包括顺序层、规则、目标和休眠结算；不含网络或浏览器。合成负载冻结时钟、延长休眠并提高 HP，不能代表合法卡牌持续时间。

前置基线与 T13 提交 `aee889e` 的 19 个源代码/配置文件逐一比较一致（允许 LF/CRLF 差异）。环境、源码及基准工具哈希、逐轮均值、聚合分位数和报告路径见 [机器可读结果](t09-summary.json)。原始报告保存在本地 `artifacts/performance/t09/`（git 忽略）。

| P01 静态 24k 活细胞 | 1.054 | 1.082 | 0.857 | 7.535 | 耗时 −18.7% |

## 补充工作负载

同一进程内交替 sparse/frontier，3 轮、每轮 30 代预热+100 代采样，仅作补充测量，不与独立进程主矩阵混合。静物海中加入始终活动的飞船，断言每个采样代 D>0；每轮最终有序快照的 SHA-256 相同。

| 工作负载 | sparse 均值 ms | frontier 均值 ms |
|---|---:|---:|
| 静物海+飞船 | 0.986 | 0.805 |
| 上述场景+1 个局部规则 | 1.558 | 0.816 |
| 上述场景+8 个局部规则 | 1.626 | 0.802 |
| 每代切换规则，交替局部规则/同化 | 1.639 | 1.508 |

前三组最后一代仅重算 18/96,022 候选；频繁规则组重算全部 96,022 个候选。该组收益收窄，说明缓存依赖稳定的规则和局部变化。

## 验证与边界

- `npm test`：138/138 通过。随后补充休眠删除/核心接触回放，定向 `tests/frontier.test.js`：9/9 通过（完整套件现有 139 项，未重复全量运行）。
- 对照初始引擎：512 组 B/S 掩码及互补生存掩码，每组连续 4 代；1000 代规则/外部写入变化；完整生产阶段回放、AI、局部到期、部署、消灭；净化圆边界、播种、同格连续换色、休眠真实删除、核心接触、后端切换及高 D。逐代比较棋盘、alive 顺序、changes 顺序、v1 差量和快照字节；小棋盘还独立重算每格 counts/votes。
- 32 位 generation stamp 回绕对照当前 sparse：初始冻结引擎存在已由先前优化修复的 stamp 回绕缺陷，不能用它作为该边界的正确性标准。
- 显式 frontier 模式浏览器烟雾通过：Chrome 153.0.8010.53，五段计算/发送/接收/应用/绘制 trace 均出现，无页面异常；固定时间主画面与小地图 PNG 与冻结渲染器字节一致。此项仅是桌面 headless 集成及固定场景像素检查，不是密集场景逐帧认证；未重复先前完整像素矩阵。

## 使用与后续

PowerShell 显式启用：

```powershell
$env:LIFEWAR_EVOLUTION='frontier'
npm start
```

恢复：设置 `LIFEWAR_EVOLUTION=sparse` 或移除该环境变量并重启。默认 `auto` 仍为 sparse；T13 协议默认保持 v1。

复测主矩阵：`node tests/performance/frontier.mjs`；补充负载：`node tests/performance/frontier-workloads.mjs`。后续若要晋级 auto，需要验证低变化识别、最短驻留/切换滞回、切换重建成本，以及真实卡牌/多房间/逐代呈现负载；当前不自动选择 frontier。
