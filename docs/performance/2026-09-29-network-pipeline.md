# 网络追赶与紧凑位图应用结果

日期：2026-09-29。实现计划见 [network-pipeline](../plans/2026-09-29-network-pipeline.md)。

## 实现

- 发送完成后按房间合并通知，继续重放尚未发送的历史，无需等待下一次演化。worker 与主线程回退均有每批 4 包、累计 256KiB 的预算，允许单个合法大包越过字节预算。缓冲阻塞时停止，恢复后继续；历史不足仍走原恢复流程。
- worker 的输出 ACK 与缓冲更新分开，缓冲通知不能提前释放输出锁。本地 WebSocket 发送完成不代表客户端已收到或画出。
- 位图先完整验证，再保存原包与瓦片索引；呈现代时直接访问位图并应用实际变化，不再展开最多约百万个 uint32 条目。新路径使用棋盘作为成员关系来源，不维护插入链表；旧协议路径保留原顺序行为。
- 客户端每 500ms 提交接收代、绘制提交代、队列数量与年龄、最近解码和应用耗时。服务器验证当前连接、epoch、范围、频率和单调性，只保留诊断，不据此改变演化、历史删除或权威状态。绘制提交不等同于物理显示器显示完成。
- 延迟数字的悬停提示和 `window.lifeWarNetwork` 提供进度诊断；旧服务器未声明能力时不发送反馈。

## 同机对照

Windows、Edge 154.0.4258.37、RTX 5070 Ti Laptop / D3D12。P04 高变化约 50 万细胞，GPU 演化，1 个浏览器客户端，DPR 1；预热 25 代，测量 100 代，各跑一轮。

对照组使用修改前的 renderer 和展开队列，实验组使用紧凑路径。两组均使用本轮服务器及解码验证代码，因此这是客户端路径对照，不是完整旧版本对完整新版本。基准使用主线程生产循环，不衡量 worker 多房间吞吐；基准页面不加载 app.js，不包含实际 HUD 和进度反馈开销。

| 指标 | 展开路径 | 紧凑路径 |
| --- | ---: | ---: |
| 解码 P50 | 5.9ms | 0.2ms |
| 应用 P50 | 17.9ms | 14.9ms |
| 帧处理 P95 | 18.3ms | 15.2ms |
| 帧处理 P99 | 18.8ms | 15.8ms |

| 每代网络字节 | 261,597.93 | 261,597.92 |
| 漏收 / 漏画 / 恢复 | 0 / 0 / 0 | 0 / 0 / 0 |

两组预热、最终棋盘哈希相同。最终哈希为 `0a8a1c159e88b3f7c0c6630b1c187cc9298e62b4a1f1f432d0498be6cabea336`。两组严格实时门槛均未通过，不能据此承诺稳定 20Hz、公网或弱设备性能。

单包内存样本：线包 260,468 字节，展开 999,962 个条目。原包加展开数组保留 4,260,316 字节；原包加紧凑索引保留 272,756 字节，其中索引 12,288 字节。这是队列保留的二进制数据量，不是整个进程堆内存或所有临时对象的总量。

棋盘编码字节没有变化，20Hz 换算仍约 5.2MB/s/客户端。本轮降低客户端处理成本和积压后的额外等待，不能让低于持续流量需求的线路长期跟上游戏。

## 验证

最终 `npm test`：190 项，186 通过、0 失败、4 项 GPU 条件跳过；`git diff --check` 通过。

新增测试覆盖完整验证后的紧凑重建、损坏包无部分写入、队列内存、无需新 tick 的大包追赶、阻塞与旧会话通知、无积压不自循环，以及主线程和 worker 的真实控制连接反馈。随机 200 代同时检查展开和紧凑重建。

浏览器回归通过 48 张主图、32 张小地图像素对照、32 次旧协议顺序对照，以及协议协商、重连和进度反馈检查。GPU 实测与常规自动化测试分别执行，常规测试中的 GPU 专项按其环境条件跳过。

## 复现

运行 `npm test`。浏览器协议验证：

```powershell
npm run test:browser:protocol -- --playwright <playwright模块路径> --executable <浏览器路径>
```

紧凑路径端到端基准：

```powershell
node tests/performance/end-to-end.mjs --variant current-v2 --scenario P04 --gpu --bitmap --generations 100 --warmup 25 --clients 1 --rounds 1 --playwright <playwright模块路径> --executable <浏览器路径> --output artifacts/performance/2026-09-29-network/compact
```

展开对照额外传 `--baseline-renderer <旧renderer.js路径>`，改用独立输出目录。旧 renderer 来源为本轮修改前提交 `a473d1a0589f51240f8869867a5218156e75d880` 的 `public/renderer.js`；夹具会同步关闭队列的 compactBitmap 选项。本机原始结果和基线副本位于被 Git 忽略的 `artifacts/performance/2026-09-29-network/`，不随提交发布。
